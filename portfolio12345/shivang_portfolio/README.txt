HOW TO ADD YOUR PHOTO:
1. Choose a clear profile photo.
2. Rename it exactly to: profile.jpg
3. Put profile.jpg in the same folder as index.html.
4. Upload both files to your GitHub Pages repository.
The photo frame currently shows SP initials until profile.jpg is added.

Keep index.html and profile.jpg in the same published folder.

PROFILE PHOTO FRAME: A 3D-style photo frame is now visible in the hero section. To show your own photo, place a portrait image named profile.jpg in the same folder as index.html before publishing.
